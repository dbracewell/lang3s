# Security Policy

## Reporting a Vulnerability

Please **do not** open public GitHub issues for security vulnerabilities.

Instead, report vulnerabilities privately to:

- david@davidbracewell.com

Please include:

- A description of the issue
- Steps to reproduce
- Affected component(s)
- Potential impact
- Any suggested mitigation (if known)

## Response expectations

- Initial acknowledgement target: **within 5 business days**
- We will investigate and validate reports as quickly as possible.
- If confirmed, we will coordinate a fix and release.

## Disclosure

We prefer responsible disclosure:

- Give us reasonable time to investigate and patch before public disclosure.
- After remediation, we may publish a security advisory with credit (if desired).

## Supported versions

At this stage, security fixes are primarily targeted at the latest code on the
`main` branch.
